# MemGAS — baseline

This folder holds a copy of the MemGAS release, trimmed to the code needed as a baseline
memory system in our HG-Mem comparison.

> **ICLR 2026**: *From Single to Multi-Granularity: Toward Long-Term Memory Association
> and Selection of Conversational Agents.*

MemGAS builds multi-granularity memory units (sessions, turns, keywords) and associates
them into a graph that is queried at retrieval time.

## Contents

| Path | Description |
| --- | --- |
| `run_qwen_retrieval.py` | **Main driver used for the paper**: runs the preprocessing → generation → embedding → graph → retrieval pipeline against a local Qwen model |
| `graph_vs_baselines_v3_copy_update.py` | HG-Mem run inside the MemGAS harness, for an apples-to-apples comparison |
| `src/` | Library code: `construct/`, `retrieval/`, `generation/`, `evaluation/`, `local_qwen.py` |
| `quickstart/` | Minimal memory API (`MemGASMemory`, `MemoryConfig`) on top of the reproduction code |
| `data/dataprocess.py` | Dataset preprocessing (reads `data/origin_data/`) |
| `requirements.txt` | Dependencies |

> Datasets are **not** duplicated in this folder: both benchmarks are downloaded once
> into the repository-level `dataset/` folder (see
> [`../../dataset/README.md`](../../dataset/README.md)) and are passed explicitly on the
> command line.

### Directories created at runtime

The pipeline writes all of its intermediate and final artifacts relative to this folder.
They do **not** ship with the repository and are (re)generated by the stages below:

| Directory | Produced by |
| --- | --- |
| `data/origin_data/` | Stage 1 — a copy of the dataset files passed on the command line |
| `data/process_data/` | Stage 1 — preprocessed conversations |
| `multi_granularity_logs/` | Stage 2 — session summaries and turn keywords |
| `data/process_embs/` | Stage 3 — embeddings |
| `graph_cache/` | Stage 4 — multi-granularity association graphs |
| `retrieval_logs/` | Stage 5 — retrieval results and metrics |

## Running the evaluation

The driver requires a **local model directory** through `--model_path`; it is exported to
the sub-modules as `LOCAL_MODEL_PATH`.

LoCoMo:

```bash
python run_qwen_retrieval.py \
    --model_path /models/Qwen2.5-7B-Instruct \
    --locomo10_path ../../dataset/locomo10.json \
    --experiments locomo10
```

LongMemEval:

```bash
python run_qwen_retrieval.py \
    --model_path /models/Qwen2.5-7B-Instruct \
    --longmemeval_s_path ../../dataset/longmemeval_s_cleaned.json \
    --experiments longmemeval_s
```

Useful flags:

- `--retriever {contriever,mpnet,minilm,qaminilm}` — embedding model for retrieval (default `contriever`).
- `--methods ...` / `--eval_k ...` — override the retrieval methods / evaluated cut-offs.
- `--few_shot N` — restrict each dataset to the first `N` conversations.
- `--skip_preprocess`, `--skip_generation`, `--skip_embeddings`, `--skip_graph`,
  `--skip_retrieval` — resume the pipeline without redoing earlier stages.

The `quickstart/` package exposes the same system as a small Python API:

```python
from quickstart import MemGASMemory, MemoryConfig

mem = MemGASMemory(MemoryConfig(storage_dir="./memgas_store", embedder="contriever"))
```
